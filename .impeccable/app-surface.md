# Company workspace

Mode: Operate. Extend the established visual world of ../30x-track, inspected in the browser before edits. The user selected reuse of this product and asked for a complete guided experience. No replacement visual identity is needed.

The content manager signs in, provides the company website or content, reviews inferred context and first audience, then arrives at a home screen with one next action. Primary navigation follows audience → opportunities → content → calendar → results, with company context, source settings and reference management available as secondary tasks.

Keep the existing restrained green/light neutral palette and familiar controls. Improve legibility, focus states, empty/loading/error recovery, responsive navigation and clear distinction of source evidence from inference. App screens are built directly in code for this session; no standing comp/code preference is stored.

All operational actions must work against scoped persisted APIs. Linked social URLs are not labeled imported. No fabricated growth, audience demographics, ROI, testimonials or automated publishing. Metrics recorded by humans are labeled manually supplied. The learning loop changes suggestions only where comparable data support an explainable adjustment.

Acceptance: registration → company context import → editable review → company creation → audience/public signal → discovered or captured reference → opportunity → original draft → review/approval → calendar → recorded publication/results. Additional checks: tenant separation, reviewer restrictions, source failures, unavailable credentials, keyboard/focus, desktop/mobile layouts.

## Direction contract (incumbent extension)

THESIS: A content manager always sees the next useful action, and can trace an opportunity back to company needs and public evidence.

OWN-WORLD: Inherit the established dark green navigation, light neutral working surface, green primary actions, DM Sans/Manrope typography and Lucide controls. Improve readable body/label sizes and focus contrast. This is an operational workspace, with functional lists, native forms and disclosures; no simulated materials or illustration assets.

STORY: Sign in → provide content → review company → confirm a first audience → home next action → public references and opportunities → original draft → review/approval → calendar → manually recorded publication/results. Public community questions contribute aggregate needs without participant profiles.

FIRST VIEWPORT: Company identity and familiar navigation provide orientation. A clear page title and next action precede supporting detail. Opportunities keep creation reachable; deep evidence and factor explanations open on request. Mobile collapses navigation and stacks controls without horizontal document scrolling.

FORM: Extension of the coherent, user-selected ../30x-track interface. No new visual world or open composition tournament: the inherited artifact is visual authority, so no concept seed or comp round applies. Code-first application screens, as the skill's Operate mode requires. All UI actions use persisted APIs and expose loading/error/empty/permission states.
