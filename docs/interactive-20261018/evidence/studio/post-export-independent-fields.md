# QA · Bitácora comercial revisada

Post · linkedin

## Gancho
Antes de pedirle a la IA que redacte el seguimiento, registra qué necesita resolver el prospecto.

## Guion
Si lideras una EdTech, puedes probar una bitácora compartida para preparar el seguimiento comercial con IA y revisión humana.

Cada entrada reúne cuatro elementos:

1. Pregunta del prospecto. Registra qué preguntó y qué información falta, sin completar los vacíos con suposiciones.

2. Borrador con IA. Pídele una respuesta basada únicamente en información aprobada. Indícale que marque los datos pendientes de confirmar. Evita incluir datos personales innecesarios.

3. Revisión humana. Una persona comprueba que la respuesta sea correcta, pertinente y que no prometa algo que el equipo no pueda cumplir.

4. Siguiente paso. Propón una acción concreta y regístrala como acordada solo cuando el prospecto la confirme.

Ejemplo ilustrativo:

Pregunta: «¿El programa se puede adaptar a los horarios de nuestro equipo?»

Pedido a la IA: «Redacta una respuesta breve usando nuestra información aprobada sobre modalidades y horarios. Si falta un dato, márcalo como pendiente. Cierra preguntando qué franjas horarias necesita el equipo».

Revisión humana: [Verificar modalidades, horarios y condiciones de adaptación antes de enviar].

Siguiente paso propuesto: pedir las franjas horarias para evaluar opciones. Si el prospecto acepta, registrar quién dará seguimiento y en qué fecha.

La bitácora deja una pregunta útil para revisar cada oportunidad: ¿qué sabemos, qué falta comprobar y qué acordamos hacer después?
