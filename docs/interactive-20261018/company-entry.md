## Reproduced defect and fix

**P2 — explicit audience was replaced by a generic topic suggestion.** Start company onboarding, paste the text below, select “Preparar mi empresa”, then “Definir mi audiencia”. Inspection returned 200, but the first audience was `Equipos comerciales`, role `Ventas y dirección comercial`, need `Encontrar prácticas para mejorar ventas y procesos comerciales.` CEO seniority and the EdTech industry were lost. This was a suggestion-quality defect, not a persistence defect: manual corrections saved correctly.

Exact owned text:

> 30X enseña inteligencia artificial práctica a líderes y equipos de América Latina. Ofrecemos talleres de IA aplicada y acompañamiento para mejorar procesos de ventas. Ayudamos a CEOs de empresas EdTech que necesitan mejorar su proceso comercial, dar seguimiento a oportunidades y convertir más ventas. Nuestra voz es clara, cercana y orientada a resultados. Trabajamos en español en Latinoamérica.

Cause: `server/company-context.mjs` selected generic topic segments in fixed order; `src/features/CompanySetup.tsx` keeps the first suggestion. The bounded fix at `server/company-context.mjs:498` prefers affirmative, explicit team declarations of the form “Ayudamos/Acompañamos/Apoyamos a … que necesita[n] …”. It preserves the supplied group, role and need, keeps confirmation/provenance wording, and retains topic suggestions as fallback. It does not claim observed consumers.

`node --test tests/interactive-company-entry.test.mjs` first failed with expected `CEOs de empresas EdTech`, actual `Equipos comerciales` ([red](evidence/company-entry/regression-red.txt)). The three new regressions plus nearby company-context and remediation tests pass **40/40** ([green](evidence/company-entry/regression-green.txt)). After restarting only this server with the same data directory and existing dist, the real onboarding UI showed the corrected generated audience at both widths, then saved it unchanged and retained it after reload. No build or commit was performed.

## Remaining heuristic limit

The prose-only company name was suggested as `example` from the unread `example.com` citation. The UI clearly labels the draft editable, and changing it to `30X — IA práctica` persisted correctly. An explicit `Empresa: 30X` declaration takes precedence over an unread citation (covered by regression). Treat an unlabeled prose name as an editable heuristic limitation; no claim was made that the website was read.

The [sanitized observations](evidence/company-entry/observations.json) include exact input, persisted semantic values, and request URLs/statuses only. An exploratory read of nonexistent `GET /api/brands` returned 404; this was a tester probe, not a UI failure. No credentials or session cookies are in this report. The server and browser tab remain available for root retest.
