# 30X interactive platform test — 18 October 2026

The editorial journey works with verified public 30X context: define the company and a proposed audience, discover references, inspect an opportunity, generate an editable piece with the live Gemini provider, review it, schedule it and export it. Testing found and fixed onboarding, source handoff and AI control defects. **URL-only onboarding remains incomplete for this company:** the website and Instagram are saved as unread links, so the test continued with a short original description based on verified public facts.

This was an agent-driven interactive test, not a usability study with recruited people or a measurement of 30X's real audience. The main app used the user's existing Google session. Independent agents used separate local QA workspaces and disposable test actors. No 30X social post was published, no messages were sent, no Instagram posts or follower records were collected, and no real audience metrics were fabricated.

## Real inputs and live services

- Website: [30x.com](https://30x.com/). Instagram: [@crece30x](https://www.instagram.com/crece30x/), verified from the official website's visible footer.
- Public context: executive education in Latin America, sales, growth and strategic AI; the catalogue includes Sales Machine and AI for Executives. The submitted description was an original factual paraphrase, not a copied website body.
- Main company: **30X · evaluación con fuentes reales**, at `http://localhost:3026`.
- Declared editorial audience: **Directivos y equipos de Latinoamérica que evalúan IA**. Its need is explicitly a team hypothesis, not observed consumer composition or course-enrolment data.
- Real text AI: the managed Gemini integration, model `gemini-3.5-flash-lite`, in the previously authorized public-test mode. No provider responses were mocked in interactive tests.
- Main discovery returned 40 Hacker News records and 10 Trends records, leaving 47 unique references; GDELT returned an explicit HTTP 429 error. An independent run retrieved all three sources successfully and retained 81 unique references. These are feed references, not measured social-network trends.
